# School Mystery

School Mystery is a Python detective game where you investigate a mystery by exploring locations, finding clues, and interacting with four different characters. Finding clues can unlock more of the storyline, dialogue, and other parts of the investigation.

> This project is currently in development.

## Features

- Explore multiple locations to search for clues.
- Finding clues can unlock new storyline and dialogue.
- Observe characters to learn about their traits.
- Question characters to gain trust and discover secrets.
- Unlock characters' phone numbers and text them using different dialogue choices.
- Save and load game progress.
- Manage collected items through an inventory system.
- Build and affect your reputation throughout the investigation.
- Use a clue satchel to access:
  - Your inventory
  - Previous observations
  - Completed quests
  - Investigation logs
- Write custom investigation logs after important events or discoveries.
- Read a specific book to unlock clue reports, which provide weekly hints about clues.

## Development

School Mystery is still in development. It is a multi-file Python project, and more of the mystery, dialogue, and gameplay is planned to be added as development continues.
